**版本**：v1.0　**生效日期**：2026-08-12

欢迎使用 Browser Agent（以下简称「本扩展」）。本协议是您（以下称「用户」或「您」）与本扩展的开发者（以下称「我方」或「运营方」）之间就使用本扩展软件及与之关联的云同步服务（`sync.crlkcloud.cyou`，以下合称「本服务」）所订立的协议。

**重要提示**：在使用本服务前，请您务必仔细阅读并充分理解本协议的全部内容。您安装、登录或使用本服务，即视为您已阅读并同意受本协议约束。若您不同意本协议的任何条款，请勿安装或使用本服务。

## 一、服务内容

1. **扩展本体**：本扩展是一款基于浏览器的自动化 Agent 工具，通过自然语言指令执行网页自动化任务（包括但不限于点击、输入、滚动、导航、内容提取等操作）。
2. **云同步服务**：本扩展提供可选的账户注册、登录与历史记录云同步功能。数据经您主动启用后同步至我方运营的服务器。
3. **附加功能**：任务模板、历史记录导入/导出、任务分享等辅助能力，随版本迭代可能新增、调整或下线。

## 二、账户与登录

1. 云同步功能需要注册账户。您应使用合法有效的邮箱注册，并对账户下的一切行为负责。
2. 您应妥善保管账户信息，因您主动泄露或保管不善导致的损失，由您自行承担。
3. 若发现账户被未经授权使用，您应及时联系我们。我方发现账户存在异常时，有权暂时冻结相关账户。

## 三、用户行为规范

您在使用本服务时，应遵守中国法律法规及本协议约定，不得：

1. 将本服务用于任何违法、违规或侵犯第三方合法权益的目的（包括但不限于：非法入侵、恶意爬取、绕过反爬与访问控制、干扰网站正常运行、侵害他人隐私等）。
2. 利用本服务批量发送垃圾信息、从事网络攻击或实施电信网络诈骗。
3. 反编译、逆向工程本扩展，或利用本服务从事不正当竞争。
4. 恶意注册、批量注册账户，或干扰云同步服务的正常运行。
5. 发布、传播违反法律或公序良俗的内容。

若您违反上述约定，我方有权视情节采取警告、限制功能、封禁账户等措施，并保留追究法律责任的权利。

## 四、自动化操作的风险与免责

1. 本扩展执行的是**网页自动化操作**。目标网站可能因自身规则、技术手段或服务变更而不允许此类操作。您在使用本扩展访问任何网站时，**应自行确认相关操作符合该网站的服务条款与适用法律**。
2. 您充分知悉并同意：自动化操作可能导致目标网站**功能异常、数据错乱、账号受限或封禁**等后果，此类后果由您自行承担，我方不承担任何责任。
3. 本扩展按「现状」提供，不保证能正确执行所有任务，也不保证操作结果与人工操作一致。因任务执行失败、结果不准确或目标网站变动造成的任何损失，我方不承担赔偿责任。

## 五、数据收集与隐私

1. **本地数据**：任务目标、执行历史、恢复记录、日志、设置等数据默认仅保存在您的浏览器本地（`chrome.storage.local`）。您可随时在扩展内删除。
2. **云端数据**：仅当您注册账户并启用云同步后，历史记录等必要数据才会上传至我方服务器。云端数据仅用于实现同步功能，不用于其他用途。
3. **最小化原则**：我方仅收集提供服务所必需的数据，不主动收集您的浏览记录、密码、Cookie 或无关个人信息。
4. **删除与更正**：您可通过扩展内操作或联系我们删除云端数据。
5. **数据安全**：我方采取合理的技术与组织措施保护数据安全，但互联网传输无法做到绝对安全，您对此知悉并同意。
6. 如我方数据收集政策有重大变化，将以适当方式通知您并更新本协议。
